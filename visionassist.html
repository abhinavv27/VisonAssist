The core problem

Detection isn't the hard part. Restraint is.

A model can label everything in a frame in real time. Announcing all of it back to someone who can't see the frame isn't assistance — it's noise they have to filter themselves, which is the exact job the system was supposed to do for them.

Every model output, spoken aloud
"Person. Bottle. Chair. Door. Stairs."
Passed through the risk & priority engine
"Stairs ahead, approximately 2 metres away."

Why it matters

Less noise. More independence.

For a blind or low-vision user, the useful output is not a catalogue of labels. It is a timely, understandable cue that supports the next decision without taking control away.

“Alone we can do so little; together we can do so much.” Helen Keller · a reminder that access and independence are shared work

How it decides

One risk score, four inputs

Every detected object is scored on how much it actually matters right now — not just what it is. Only the highest-risk item in frame gets spoken, and low-risk clutter is suppressed entirely.

risk score  =  proximity  +  centrality  +  base danger  +  movement factor
ObjectBase dangerDistancePositionResult
Stairs852.0 mCentre Spoken immediately
Vehicle904.0 mCentre Spoken immediately

Bottle101.0 mRight Suppressed

System design

Hardware-agnostic by construction

The reasoning layers never import from a specific camera or sensor. Today the input is a laptop webcam; the same perception, risk, and speech code moves onto a phone stream or custom smart glasses without a rewrite.

Input layer
Laptop webcam · smartphone stream · hardware camera
Perception layer
YOLOv8 detection · EasyOCR · depth & proximity · left/centre/right position
Context & risk engine
What is nearby, where, and how urgent
Priority engine
Selects one top item · debounces repeat alerts · filters noise
Response generator
Concise template sentence, e.g. "Stairs ahead, approximately 2 m"
Offline text-to-speech
pyttsx3 / native SAPI · non-blocking queue · earphones or speakers

Try it yourself

This runs on your machine, not this page

VisionAssist is a local Python application built on OpenCV, YOLOv8, and an offline speech engine. It needs direct access to a camera and to your system's audio output, which a browser tab can't grant. There's nothing to click "run" on here — you clone the repo and launch it locally instead.

Note

Launching the app opens its own window on your desktop — either a native OpenCV window, or a Streamlit dashboard served at localhost and opened in your browser. Either way, the model and camera feed run locally. This page can only show you how to start it, not run it for you.

01 — Clone & install
git clone git@github.com:abhinavv27/VisonAssist.git
cd VisonAssist
pip install -r requirements.txt
02 — Verify the build
py -m pytest tests/
03 — Desktop window
py app.py               # opens an OpenCV window using your webcam
py app.py --mock        # no webcam? runs on a simulated feed
1 Quick Look
2 Obstacle Awareness
3 Read (OCR)
r Reset cooldown
q Quit
04 — Local dashboard
py app.py --streamlit   # opens the accessible dashboard at localhost
